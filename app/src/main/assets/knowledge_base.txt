AGENT KNOWLEDGE BASE
=====================

Android Accessibility Service - Phone Control Tools:

click_text(label) - Find UI element by text and click it
click_coord(x, y) - Tap screen at specific coordinates
type_text(text) - Enter text into focused input field
scroll(direction) - up/down/left/right scroll
go_back() - Press hardware back button
go_home() - Go to home screen
recent_apps() - Open recent apps overview
swipe(x1,y1,x2,y2,duration) - Custom swipe gesture
open_app(package) - Launch app by package name
wait(ms) - Pause for milliseconds
read_screen() - Get current screen text content

Screen Coordinates:
- Width: 1080px (typical)
- Height: 2400px (typical)
- Top status bar: 0-100px
- Bottom nav bar: ~2200-2400px
- Notification shade: swipe down from top (540, 0) to (540, 500)
- Home gesture: swipe up from (540, 2300) to (540, 100)
- Back gesture: swipe from (0, 1200) to (200, 1200)

Troubleshooting Tips:
1. If element is not clickable, try scrolling to make it visible
2. Use read_screen() first to understand current screen
3. Wait 300ms after clicking for screen transition
4. For text input, click field first then type
5. For lists, scroll then read_screen to find target
